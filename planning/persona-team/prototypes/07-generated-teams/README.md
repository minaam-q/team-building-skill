# Prototype: what a generated team looks like

PROTOTYPE. Throwaway. Made for [What a generated team looks like](../../issues/07-what-a-generated-team-looks-like.md).
Three rough takes to react to. Each tries a different form on purpose.

| Take | Project | Voices | Form | Size |
| --- | --- | --- | --- | --- |
| [A](a-dinner-pair/in-chat.md) | Dinner for eight | 2 | In the chat, nothing saved, five sentences per persona | about 30 lines with first use |
| [B](b-launch-four/team.md) | Letterpress calendar pre-order | 4 | One file, personas as cards with fixed fields | about 110 lines |
| [C](c-research-six/team.md) | Why iridium is brittle | 6, one a guest | Folder: `team.md`, a prose file per persona, `design_notes.md` | 40 + 6 × 30 + 45 lines |

## What each persona description contains

| Part | A | B | C |
| --- | --- | --- | --- |
| What they start from | yes | yes | yes |
| Habitual question | yes | yes | yes |
| Their criterion ("right when…") | yes | yes | yes |
| What they overdo, and the correction | yes | yes | yes |
| Strong at, quiet on | no | yes, as two fields | only in the design notes |
| Story | no | no | two sentences, placed after the habits |
| Relation to others | one sentence for the pair | the pair only | the pair, and "in the group" for the rest |
| When the user is wrong; what changes their mind | no | yes | yes |
| How to answer | no | no | yes |
| A line in their voice | shown by use | yes | yes |
