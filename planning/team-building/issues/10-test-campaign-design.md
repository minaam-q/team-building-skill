# Test campaign design

Type: grilling
Status: open
Blocked by: 03, 09

## Question

How is the skill tested? Settle: the axes of variation for hypothetical projects and users (domain, size, stakes, user temperament, how much the user knows what they want, language) and how wild they get; who plays the user and how; which models run the skill and which judge; how many runs; what is compared against what (the skill versus no skill, versus a single advisor, versus the research group skill); the budget; and what the campaign has to show before the skill is called ready.

Read first: `../research-group-skill/research/ir_case_study_2026-11-14/prospective_evaluation.md`. It proposes
the comparison that separates personas from procedure (neutral assistant; workflow with neutral role names;
workflow plus personas; one persona without the workflow) under equal model and budget, and five frozen tasks
taken from real Ir project states.


Note from [What a team remembers](13-what-a-team-remembers.md): part of a team's effect may run through the human,
who asks differently depending on which persona they address. A simulated user will not do this unprompted, so
the campaign as sketched cannot see it; full recordings from real use are the only current evidence.

Notes from [What makes a generated team good](09-what-makes-a-team-good.md): the rubric fixes the reference for
coverage (one careful answer, same model, same token budget, no skill) and leaves the further arms to this
ticket. Scenarios must state project size, whether the project makes factual claims, a seeded list of issues,
and, for some, a planted flaw in the user's private fact sheet. Thresholds wait for the pilot. Memory and
retention are not judged by the rubric and would need multi-session scenarios; decide here whether the campaign
has any. The effect that runs through the human stays unobservable here.


*Note from [Portraits and visual pages](14-portraits-and-visual-pages.md), 2026-11-14: portraits are outside the campaign in v1. Decide here whether to include one text-only scenario: a likeness request is declined and no real name reaches a prompt.*
